# 📻 Red Ant RC — yoRadio Remote Control for Android

**[📱 Platform: Android](https://github.com)** • **[📻 Hardware: ESP32 / yoRadio](https://github.com)** • **[📥 Download APK: (Releases)](https://github.com/GEOPIS/RED_ANT_WEB-FONTROL-FOR-ANDROID/releases/tag/V1.0)**



**[EN]** A lightweight, fast, and dark-themed Android Remote Control application designed specifically for managing your **yoRadio (ESP32)** internet radio over your local Wi-Fi network.  
**[GR]** Μια ελαφριά, γρήγορη εφαρμογή Android σε σκούρο θέμα (Dark Mode), σχεδιασμένη ειδικά για τον απομακρυσμένο έλεγχο του ιντερνετικού ραδιοφώνου **yoRadio (ESP32)** μέσω τοπικού δικτύου Wi-Fi.

---

## ✨ Features / Χαρακτηριστικά

* **💾 Auto-Save & Auto-Connect IP:** Automatically remembers your last used yoRadio IP address and connects immediately on startup. *(Αυτόματη αποθήκευση της τελευταίας IP και άμεση σύνδεση κατά το άνοιγμα).*
* **🚦 Live Connection Status:** Visual button feedback (`CONNECTING...`, `CONNECTED`, `NOT FOUND`) with dynamic color indicators. *(Ζωντανή ένδειξη κατάστασης σύνδεσης με αντίστοιχα χρώματα).*
* **🖥️ Collapsible Top Bar:** Hide or show the IP address bar with a single tap on the top-left arrow icon to maximize screen space. *(Απόκρυψη/εμφάνιση της μπάρας IP με ένα πάτημα για μέγιστο χώρο στην οθόνη).*
* **🔄 Auto-Rotation & Zoom Support:** Seamless switching between Portrait and Landscape modes so all yoRadio menus (station search, equalizer, settings) fit comfortably. *(Υποστήριξη περιστροφής οθόνης και zoom για άνετη πλοήγηση σε όλα τα υπομενού).*
* **🔆 Keep Screen On:** Prevents the device screen from sleeping while controlling your radio. *(Διατηρεί την οθόνη ενεργή όσο χρησιμοποιείτε την εφαρμογή).*
* **💬 Full Dialog Support:** Native Android confirmation popups for yoRadio actions (such as RX/TX mode reboot prompts). *(Πλήρης υποστήριξη αναδυόμενων παραθύρων επιβεβαίωσης).*

## 📥 Installation / Εγκατάσταση

1. Go to the **[Releases](https://github.com/releases)** page of this repository. *(Πηγαίνετε στη σελίδα **Releases** αυτού του repository).*
2. Download the latest **`Red_Ant_rc-signed.apk`** file to your Android device. *(Κατεβάστε το πιο πρόσφατο αρχείο **`Red_Ant_rc-signed.apk`** στη συσκευή σας).*
3. Open the downloaded file and allow installation from unknown sources if prompted. *(Ανοίξτε το αρχείο και επιτρέψτε την εγκατάσταση από άγνωστες πηγές αν σας ζητηθεί).*

---

## 🚀 How to Use / Οδηγίες Χρήσης

1. Make sure your Android phone and your **yoRadio (ESP32)** are connected to the **same Wi-Fi network**. *(Βεβαιωθείτε ότι το κινητό και το yoRadio είναι συνδεδεμένα στο ίδιο δίκτυο Wi-Fi).*
2. Open **Red Ant RC**, enter your yoRadio's local IP address (e.g., `192.168.1.50`), and tap **Connect**. *(Ανοίξτε την εφαρμογή, πληκτρολογήστε την τοπική IP του yoRadio και πατήστε σύνδεση).*
3. Once the button turns green (**`CONNECTED`**), tap the top-left arrow icon to hide the IP bar and enjoy full-screen control! *(Μόλις η ένδειξη γίνει πράσινη, πατήστε το βέλος πάνω αριστερά για να κρύψετε την μπάρα).*
